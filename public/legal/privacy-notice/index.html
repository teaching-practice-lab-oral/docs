先看重點

本隱私權政策同時是依《個人資料保護法》第 8 條及第 9 條提供的個人資料蒐集、處理及利用告知事項。以下先用白話整理重點，後面的完整內容會逐項說明法定告知事項。

為什麼需要資料用來建立帳號、提供英文面試練習與 AI 回饋、保存學習紀錄、讓教師評量，以及維護系統安全。
會處理哪些資料包括姓名、學號、班級、電子郵件、作答、錄音、評分、操作與資訊安全紀錄。
資料會到哪裡主要系統位於美國聖荷西，錄音與問題附件存放於日本東京；部分語音處理會經過台灣伺服器與 OpenAI API。
會保存多久一般帳號、課程、錄音及操作紀錄原則上保存至 2027 年 9 月 1 日；研究資料另依研究同意內容處理。
您可以提出哪些要求您可以依法查詢、閱覽、取得副本、補充、更正、停止處理或要求刪除個人資料。
研究參與另外決定閱讀本政策不代表同意參與研究，也不影響您另外決定是否參與研究。

四、為什麼需要這些資料

我們會基於下列目的蒐集、處理及使用您的個人資料：

  1. 建立、驗證及管理使用者帳號。
  2. 辨識學生身分、班級及課程資格。
  3. 提供英文面試練習、錄音、語音播放及作答功能。
  4. 提供 AI 分析、學習提示、模擬問答及學習回饋。
  5. 保存學習歷程、作答內容、練習次數及完成進度。
  6. 讓授課教師或已獲授權的助教進行課程評量、回饋及成績管理。
  7. 寄送帳號通知、密碼重設、作業提醒及其他必要系統通知。
  8. 維護系統正常運作、資訊安全、異常偵測、問題排查、備份及復原。
  9. 處理使用者詢問、系統錯誤回報、申訴、權益請求及相關行政作業。
  10. 配合校務、課程、計畫成果查核、稽核及依法應辦理的事項。
  11. 只有在另外完成研究倫理審查核准的知情同意程序後，才將獲得授權的資料用於研究分析及成果發表。

如果您不同意參與研究，資料不會因此直接納入研究分析；但完成課程及維持系統運作所需的資料，仍可能依課程及相關規定處理。

五、資料從哪裡來

  1. 學校、課程或授課人員提供：由學校、授課教師或經授權管理人員依選課、班級或課程名冊建立或匯入的姓名、學號、電子郵件、班級、課號及組別資料。
  2. 使用者自行提供：備用電子郵件、作答、草稿、錄音、心得、回饋、問題描述、照片、螢幕截圖及其他上傳內容。
  3. 教師或授權人員建立：教師評分、評語、作業安排、帳號狀態及課程管理紀錄。
  4. 系統自動產生：登入及操作時間、IP 位址、裝置及瀏覽器資訊、工作階段、使用量、條款與隱私權政策確認、錯誤、資訊安全紀錄，以及練習期間進入或離開全螢幕、頁面隱藏、視窗失焦、貼上遭阻擋與異常大量輸入等操作事件。
  5. 受託服務回傳：郵件寄送狀態、退信或抑制紀錄、Cloudflare Turnstile 人機驗證結果，以及第三方服務提供功能時產生的必要技術紀錄。

部分帳號識別及課程資料不是由您直接提供。系統第一次使用這些資料時，會透過本政策說明資料來源及《個人資料保護法》要求告知的事項；法律另有免告知規定時，依該規定辦理。

  3. 問題回報照片及附件：使用者因回報系統錯誤、功能異常、操作問題或提出技術支援需求所上傳的照片、螢幕截圖及其他附件，原則上保存至民國 116 年 9 月 1 日止。
  4. 系統操作及資訊安全紀錄：包含登入、登出、IP 位址、裝置資訊、登入工作階段、錯誤、人機驗證、安全檢查，以及練習期間進入或離開全螢幕、頁面隱藏、視窗失焦、貼上遭阻擋與異常大量輸入等操作紀錄，原則上保存至民國 116 年 9 月 1 日止。

保存期限屆滿或蒐集目的消失後，相關資料會依資料性質及實際情況刪除、銷毀、匿名化或停止使用。如果法律或其他規定仍要求保存，則依該規定辦理。

八、資料會在哪些地區處理

（一）中華民國境內

您在中華民國境內使用本系統時，以及已獲授權的人員為了課程教學、評量、研究計畫、行政管理、系統維護或處理個人資料權利請求時，會在必要範圍內使用資料。

（二）台灣語音處理伺服器

系統可能將部分錄音檔案或產生示範語音所需的英文文字，暫時傳送至位於台灣的語音處理伺服器，用來進行錄音格式轉換、語音辨識或示範語音產生。

這台伺服器只在完成該次處理所需的期間接收資料，不負責登入、帳號、作業、課程資料庫或永久檔案儲存。處理完成後會將結果傳回主系統；如果伺服器無法使用，主系統會接手處理。

（三）美國加利福尼亞州聖荷西

本系統主要使用 Oracle Cloud Infrastructure 美國西部聖荷西區域（us-sanjose-1），提供應用程式主機、資料庫、系統操作紀錄及其他系統運作所必要的雲端基礎設施服務。

本系統使用 Oracle Cloud Infrastructure Email Delivery 電子郵件傳送服務，處理寄件人及收件人的電子郵件地址、郵件主旨、郵件內容、寄送狀態、退信紀錄及郵件抑制紀錄等必要資料。

（四）日本東京都

本系統使用 Oracle Cloud Infrastructure 日本東京區域（ap-tokyo-1）的物件儲存服務，保存下列檔案：

  1. 使用者於英文面試練習、作業或其他課程活動中產生及上傳的錄音檔案。
  2. 使用者因回報系統錯誤、功能異常、操作問題或提出技術支援需求，而上傳至本服務的照片、螢幕截圖及其他相關附件。

上述檔案可能包含使用者的聲音、畫面內容、裝置畫面、帳號資訊或其他可識別個人身分的資料。

使用者於回報問題時，應避免上傳與問題排查無關的個人資料、帳號密碼、驗證碼、金融資料、醫療資料或其他敏感及機密資訊。

（五）Cloudflare Turnstile 全球服務節點所在地

本系統使用 Cloudflare Turnstile 提供人機驗證服務，以辨識自動化程式，並降低帳號遭濫用、惡意登入或大量自動化請求的風險。

使用者進行登入、密碼重設申請或其他需要人機驗證的操作時，其 IP 位址、瀏覽器及裝置資訊、連線時間、人機驗證結果及必要技術資訊，可能經由 Cloudflare 的全球服務節點進行即時處理。

（六）OpenAI API 及其服務提供者所在地

為提供錄音辨識、英文作答分析、草稿修正、學習提示、面試模擬、AI 回饋及文字轉語音等功能，本系統可能將執行功能所必要的錄音檔案、語音內容、作答文字、對話內容、系統提示及相關資訊傳送至 OpenAI API。

OpenAI Audio Transcriptions API以 whisper-1 模型進行錄音檔案的英文語音辨識、文字轉錄及必要的字級時間資訊分析。
OpenAI Chat Completions API處理英文作答分析、文法修正、草稿回饋、學習建議、面試模擬及其他文字內容生成；目前預設文字模型為 gpt-5.4-mini。
OpenAI Audio Speech API將系統提供的英文文字轉換為語音，供跟讀、示範或相關學習功能使用；目前使用 gpt-4o-mini-tts 模型，角色扮演語音使用 cedar，跟讀示範語音使用 marin。

相關資料可能在中華民國境外處理，包括美國、日本、歐洲及 OpenAI 現行服務提供者所在的其他地區。OpenAI 的服務提供者及處理地區可能調整，最新資訊請參閱其次級處理者清單。

除非本系統另行啟用特定的資料駐留或區域處理功能，相關資料處理不保證限定於中華民國境內或單一國家或地區。

本系統使用的生成式 AI、語音辨識及文字轉語音服務均由 OpenAI 提供，未使用其他非 OpenAI 的第三方 AI 或語音服務。

（七）其他維持系統運作所需的服務所在地

如因備份、監控、資訊安全、郵件或其他必要功能使用其他受託服務，個人資料可能於該服務提供者及其受託處理者的機房或服務所在地進行必要處理。

如資料須由境外受託服務處理，本系統將依資料最小化原則，僅傳送提供該項功能所必要的資料，並採取合理的存取權限、傳輸加密及資訊安全措施。

如果使用者在作答文字、錄音、照片、螢幕截圖或其他附件中自行提供姓名、學號、聯絡資訊或其他個人資料，這些資訊可能隨檔案或內容傳送至上述服務所在地。因此，使用者不應提供與課程活動或問題排查無關的敏感或機密資料。

十、資料如何使用與儲存在瀏覽器

  1. 建立帳號、身分驗證及權限管理。
  2. 顯示、儲存、查詢、修改、備份及復原學習資料。
  3. 將錄音檔案傳送至 OpenAI Audio Transcriptions API，並使用 whisper-1 模型進行英文語音辨識、文字轉錄及必要的字級時間資訊分析。
  4. 將語音辨識所得文字、使用者作答、草稿、對話內容、系統提示及執行功能所必要的相關資訊，傳送至 OpenAI Chat Completions API，以進行英文作答分析、文法修正、草稿回饋、面試模擬及產生學習建議。
  5. 將系統提供的英文文字傳送至 OpenAI Audio Speech API，使用 gpt-4o-mini-tts 模型產生語音，以提供跟讀、示範或相關學習功能。
  6. 讓授課教師或已獲授權的助教查閱、評量、批改、匯出及管理課程。
  7. 寄送系統或課程相關電子郵件。
  8. 分析系統使用狀況、進行人機驗證、偵測異常行為及維護資訊安全。
  9. 保存及檢視使用者為回報系統問題而上傳的照片、螢幕截圖或其他附件，以進行問題排查及技術支援。
  10. 經研究參與者知情同意程序授權後，以去識別化、編碼或統計方式進行研究分析及成果發表。

對外公開的研究報告、論文、簡報或其他成果，不會揭露可直接識別個別使用者的姓名、學號、電子郵件或其他識別資訊。

必要的 Cookie 與瀏覽器儲存

本系統使用必要的登入及跨站請求防護 Cookie 維持身分驗證與系統安全；其中登入憑證採 HttpOnly Cookie，前端程式無法直接讀取。系統不使用廣告或行銷追蹤 Cookie。

為維持操作流程，瀏覽器的 sessionStorage 可能暫存使用者名稱、角色、登入狀態、導覽狀態及角色扮演關鍵字草稿；localStorage 可能暫存尚未送出的學習心得草稿及 PWA 安裝狀態。這些資料保存在使用者裝置，可透過登出、完成送出、關閉工作階段或清除瀏覽器網站資料移除；使用共用裝置時應於完成後登出並關閉瀏覽器。

十一、OpenAI 與其他外部服務如何處理資料

為提供錄音辨識、英文作答分析、草稿修正、面試模擬、學習回饋及文字轉語音功能，本系統會將執行功能所必要的錄音檔案、語音內容、作答文字、草稿、對話內容、系統提示及相關資訊傳送至 OpenAI API。

（一）錄音辨識

使用者的錄音檔案會傳送至 OpenAI Audio Transcriptions API，並使用 whisper-1 模型進行英文語音辨識及文字轉錄。

（二）文字分析及內容生成

語音辨識所得文字、使用者輸入的作答、草稿、對話內容及執行功能所必要的系統提示，會傳送至 OpenAI Chat Completions API，以進行：

  1. 英文作答分析。
  2. 文法及用字修正。
  3. 草稿回饋及範例生成。
  4. 面試問題及追問生成。
  5. 面試角色模擬。
  6. 學習建議及整體回饋。
  7. 將分析結果整理為系統所需的結構化資料。

系統使用的文字模型由系統設定決定，目前預設為 gpt-5.4-mini。模型可能因系統功能、效能、安全性或服務調整而變更。

（三）文字轉語音

為提供英文跟讀、發音示範或相關語音播放功能，系統提供的英文文字可能傳送至 OpenAI Audio Speech API，並使用 gpt-4o-mini-tts 模型產生 MP3 語音檔案。角色扮演語音目前使用 cedar，跟讀示範語音目前使用 marin；兩者依學習用途套用不同的語音指示。

文字轉語音所傳送的內容原則上為系統產生或課程功能所需的英文文字，不需要傳送使用者的原始錄音檔案。

（四）OpenAI 保存與模型訓練

OpenAI 的保存規則會依 API 功能不同而有差異。依 2026 年 8 月 1 日查閱的官方資料控制說明，Chat Completions API 與 Audio Speech API 預設可能保留防止濫用所需的紀錄，最長 30 天；Audio Transcriptions API 的表列預設則不保留這類紀錄或應用程式狀態。依法必須保存或官方說明列出的特殊情況，可能不受上述期間限制。

實際保存情況仍會受到本系統 API 帳戶、專案、端點及資料控制設定影響。OpenAI 表示 API 平台的輸入與輸出預設不會用於訓練或改進模型，除非帳戶持有人明確選擇分享。本計畫不會為模型訓練目的主動分享學生資料。最新政策以 OpenAI 的商務資料隱私說明為準。

（五）資料最小化及使用者注意事項

本系統使用的生成式 AI、語音辨識及文字轉語音服務均由 OpenAI 提供，未使用其他非 OpenAI 的第三方 AI 或語音服務。

系統將依資料最小化原則，避免向 OpenAI 傳送與功能無關的姓名、學號、電子郵件或其他直接識別資料；但使用者自行於作答文字、草稿、對話或錄音中提及的資訊，仍可能包含於傳送內容中。

使用者不應於作答、草稿、對話或錄音中提供與課程無關的身分證字號、金融資料、醫療資料、密碼、驗證碼、私人通訊內容或其他敏感及機密資訊。

十二、您可以行使哪些個人資料權利

依《個人資料保護法》，您可以就自己的資料提出下列要求：

  1. 查詢或閱覽。
  2. 提供資料副本（法律用語為「製給複製本」）。
  3. 補充或更正。
  4. 停止蒐集、處理或利用。
  5. 刪除。

您可以透過本頁第十五節所列的計畫主持人電子郵件、電話或其他經學校公告的管道提出申請。提出申請時，可能需要提供足以確認本人身分及請求範圍的資料；查詢、閱覽或要求資料副本時，可能依法收取必要的成本費用。

查詢、閱覽或要求資料副本的申請，原則上會在十五日內決定是否受理；補充、更正、停止蒐集／處理／使用或刪除的申請，原則上會在三十日內決定。依法需要延長時，會在原期限內說明原因並通知申請人。

如依法、課程評量、申訴處理、資訊安全或法定保存義務仍有保存必要，部分請求可能無法立即辦理，屆時將說明理由。

上述權利不能預先放棄，也不能用另外約定的方式限制。

十三、您可以選擇不提供資料；可能有什麼影響

您可以決定是否提供非課程或系統運作所必要的資料。

但如不提供帳號識別、班級、電子郵件、作答、錄音或教師評量所必要的資料，可能產生以下影響：

  1. 無法建立或驗證帳號。
  2. 無法使用相應的作答、錄音、AI 回饋或教師評量功能。
  3. 無法完成授課教師指定的課程活動。
  4. 無法接收帳號、密碼重設或作業相關通知。

是否參與研究，由您另外透過研究倫理審查核准的研究參與者知情同意程序決定。

不參與研究本身不影響您的課程成績、受教權益或與授課教師之關係；但仍應依課程要求完成一般教學活動及指定作業。

十四、系統如何保護資料

系統將採取合理的技術及管理措施保護個人資料，包括：

  1. 帳號權限及身分驗證。
  2. 密碼雜湊儲存及具適當安全強度之傳輸加密。
  3. 存取控制及操作紀錄。
  4. 備份、監控及資訊安全防護。
  5. 限制經授權人員於必要範圍內存取資料。
  6. 發生個人資料事故時，依相關規定進行處理及通知。

但網路、跨境傳輸及資訊系統無法保證完全沒有風險。您也應妥善保管帳號密碼，避免在共用或不可信任的裝置登入。
